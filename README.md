# ALX Projects 0x07-0x11 - Advanced Frontend Setup

Collection of advanced ALX frontend projects covering Next.js, TypeScript, testing, and production deployment.

## 📚 Projects Included

### alx-project-0x07
- **Focus:** Next.js fundamentals
- **Topics:** SSR, SSG, API routes, file-based routing

### alx-project-0x08
- **Focus:** TypeScript with React
- **Topics:** Type safety, interfaces, generics

### alx-project-0x09
- **Focus:** Testing React applications
- **Topics:** Jest, React Testing Library, E2E tests

### alx-project-0x10
- **Focus:** State management (Redux/Zustand)
- **Topics:** Global state, actions, reducers

### alx-project-0x11
- **Focus:** Production deployment
- **Topics:** Build optimization, CI/CD, hosting

## 🎯 Learning Objectives

- Build production-ready Next.js applications
- Implement type-safe React with TypeScript
- Write comprehensive test suites
- Manage complex application state
- Deploy to production (Vercel/Netlify)

## 🚀 Getting Started

Each project has its own setup:

```bash
cd alx-project-0x07
npm install
npm run dev
```

## 🛠️ Tech Stack

- **Framework:** Next.js 13+
- **Language:** TypeScript
- **Testing:** Jest, React Testing Library
- **State:** Redux Toolkit or Zustand
- **Deployment:** Vercel, Netlify, or custom

## 📖 Skills Demonstrated

- Server-side rendering (SSR)
- Static site generation (SSG)
- TypeScript type system
- Unit and integration testing
- State management patterns
- Production deployment workflows
